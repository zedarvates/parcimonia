# Validation scope

Candidate 0.4.2 changes packaging, listing/skill instructions and displayed server
version. Its four vendor runtime files must match the original 0.4.1 file inventory.
The new candidate requires its own report; historical native calls must not be
relabelled as an installation of this candidate. Stdio tests prove a transport/tool
operation. Clean Codex plugin ownership, desktop rendering, model-driven tool choice,
Linux/macOS installation and directory approval are separate evidence scopes.
Library 0.5.1's full CI does not automatically qualify this new plugin package.
