# Workflow de démonstration

Cette fixture n'est pas un skill installé ou une autorisation d'exécuter.
Examiner la révision du tableau synthétique, proposer le mécanisme de calcul
local et vérifier le résultat. Conserver les erreurs et les coûts inconnus.
Ne transmettre aucune donnée à un service externe.
